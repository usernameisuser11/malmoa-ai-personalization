# malmoa-ai-personalization

말모아 AAC의 개인화 AI 문장 추천 기능을 실제로 검증하기 위한 통합 실험 저장소입니다.

## 목표
- 기존 SMU-SENSE 사용자/보호자 프론트와 Spring Boot 백엔드 구조를 재사용
- 사용자 의사소통 수준, 이해/표현 가능한 문장 길이, 개인 어휘를 기반으로 AI 문장 추천
- 즐겨찾기/사용 빈도/보호자 커스터마이징을 Gemini 프롬프트에 반영
- 긴급어는 고정 데이터로 안전하게 제공
- Neon PostgreSQL 연동
- Render 배포

## 기본 구조
- `frontend/`: Next.js + TypeScript
- `backend/`: Spring Boot + PostgreSQL
- `docs/`: 기획 및 설계 문서

## 환경변수
실제 비밀값은 저장소에 커밋하지 않습니다. `.env.example`을 참고해 로컬/Render 환경변수로 설정합니다.

## 진행 원칙
1. 사용자의 진단명만으로 언어 수준을 판단하지 않음
2. 실제 수용/표현 언어 능력을 생성 제약으로 사용
3. 카드 표준어와 사용자별 별칭/표현을 분리 저장
4. AI가 사용자를 대신해 새 의도를 만들지 않도록 함
5. AI 출력은 최대 어절 수/개인 어휘 반영/금지 표현을 후검증
