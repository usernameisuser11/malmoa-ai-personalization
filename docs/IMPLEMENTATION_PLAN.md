# 구현 계획

## 기존 코드 기준

- 사용자 프론트: `SMU-SENSE/frontend@feature/jian`
- 알림 포함 백엔드: `SMU-SENSE/backend@feature/yunji-gardian-alarm`

새 저장소는 기존 코드를 망가뜨리지 않고 독립적으로 검증하기 위한 통합 실험판이다.

## 이번 실험판에서 검증할 핵심
1. 보호자가 실제 의사소통 수준을 설정한다.
2. 표준 상징어와 사용자별 표시어/별칭/TTS 문구를 분리한다.
3. 즐겨찾기·중요어·사용 빈도를 개인 어휘로 누적한다.
4. Gemini에 사용자 수준 + 상황 + 선택 카드 + 개인 어휘를 함께 제공한다.
5. 생성 후 최대 어절 수를 코드에서 다시 검사한다.
6. 일반 Gemini 결과와 개인화 결과를 같은 입력으로 비교한다.
7. 긴급어는 AI와 분리해 항상 고정 접근 가능하게 둔다.

## 지적 수준 처리 원칙
`지적장애 경도/중등도/중도 -> N단어`를 하드코딩하지 않는다. 진단명은 사용자의 실제 수용·표현 언어 능력과 일치하지 않을 수 있기 때문이다. 제품 입력값은 `이해 가능한 최대 어절`, `표현 가능한 최대 어절`, `어휘 난이도`, `추상 표현 여부`, `이유 표현 여부`처럼 생성에 직접 쓸 수 있는 값으로 구성한다.
